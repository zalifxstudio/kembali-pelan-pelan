# Kembali, Pelan-Pelan

Buku HTML 72 halaman tersedia dalam folder book. Buka book/index.html secara lokal atau kunjungi /book/ pada versi GitHub Pages. Isinya dibagi ke dalam tujuh bab utama, rencana 28 hari yang fleksibel, sumber dukungan, dan penutup. Buku memakai navigasi daftar isi, kontrol halaman, pembesaran huruf, navigasi keyboard, dan ilustrasi kartun vektor ImageGen dengan maskot laki-laki.

Halaman latihan tetap berada pada index.html. Buku tidak meminta jurnal intim dan tidak mengirim data. Pengingat halaman disimpan secara lokal hanya jika pembaca mengaktifkannya.

Validasi klinis, tinjauan ahli agama, dan uji perangkat fisik belum dilakukan. Buku tidak menggantikan diagnosis, terapi, atau fatwa.
